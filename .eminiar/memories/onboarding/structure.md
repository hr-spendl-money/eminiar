Top-level layout of the eminiar repo:
- `src/` — all TypeScript (ESM, NodeNext). Node entry points bundled by `tsup.config.ts`: `src/server.ts` (MCP server), `src/hook.ts` (hook runner), `src/cli.ts` (CLI). The browser bundle `src/ui/web/main.tsx` is built by `tsup.web.config.ts` into `dist/ui/` (Preact JSX, `tsconfig.web.json`). Shared root modules: `config.ts`, `paths.ts`, `project.ts`, `context.ts`, `doctor.ts`, `version.ts`.
- `bin/` — POSIX sh shims (`_resolve.sh`, `em-server`, `em-hook`, `eminiar`) that pick the pinned node and fall back to the stable copy in `~/.eminiar/root-path`. Hooks must never block Claude.
- `hooks/hooks.json`, `.claude-plugin/plugin.json` (inline `mcpServers.eminiar`; deliberately no repo-root `.mcp.json`), `skills/<name>/SKILL.md`, `scripts/` (`copy-grammars.mjs` vendors five tree-sitter wasm grammars: typescript, tsx, javascript, python, go; `gen-schema.ts` writes `eminiar.config.schema.json`), `tests/unit` + `tests/integration` (vitest), `vendor/grammars/` (committed wasm), `dist/` (gitignored), `.eminiar/memories/` (committed memories, this file included).

Where each kind of code lives under `src/`:
- `tools/` — one file per MCP tool (`em_execute`, `em_search`, `em_symbols`, `em_architecture`, `em_graph_changes`, `em_index_status`, …; `em_graph.ts` holds graph_query/graph_impact/graph_add/reindex and `ensureGraph`). `tools/index.ts` lists them; `types.ts` has `defineTool`.
- `graph/` — the knowledge graph. `treesitter.ts` parses TS/JS and dispatches Python/Go to `languages/{python,go}.ts` (shared loader, `RefCollector`, `complexityOf` in `languages/parser.ts`); `routes.ts` (route node helpers, framework table, Next.js file routes); `resolve.ts` (relative imports, tsconfig paths, workspace packages via package.json exports); `reindex.ts` (file discovery, `file_index` status rows, `index_runs`, `CODE_INDEX_VERSION`, `finalizeGraph`, `indexFreshness`); `link.ts` (post-index pass: barrels, default exports, Go sibling files, inherited methods, demote/restore unresolved edges, external file stubs); `metrics.ts` (fan-in/out, loc, complexity, hotspot score, clusters, cycles → `graph_metrics` + meta) with pure algorithms in `clusters.ts`; `changes.ts` (git diff → symbols → blast radius); `query.ts` (impact, dependencies, neighbors, path, hotspots, coupled, orphans, deadCode, routes, pattern); `architecture.ts` (structured project summary + text); `git.ts` (co-change, churn; `--relative` paths); `ids.ts`, `format.ts`.
- `code/` — `backend.ts` (CodeBackend: supports/languageOf/parse/references), `treesitter-backend.ts`, `namepath.ts`, `symbols.ts` (overview/find/children/symbolBody).
- `history/` — git history comprehension behind `em_history` and the dashboard History tab: `log.ts` (git log --all --full-history --numstat, refs, tags, blame, `git log -L`, working tree), `classify.ts` (commit kind/scope/issues/PR/revert from the message and file list), `szz.ts` (fix-origin trace: blame the lines a fix removed), `model.ts` (HistoryModel cached per root keyed on HEAD + ref fingerprint; file and commit risk scores; lessons; indexes messages as source `git`; writes the `history_brief` meta row), `narrate.ts` (text renderers for the tool). UI side: `src/ui/history-api.ts` payloads, `src/ui/web/history/` (charts.tsx, lanes.ts pure DAG lane layout), `views/History.tsx`.
- `memory/` — `frontmatter.ts` (keys name, kind, status, supersedes, tags, related, created, updated) and `store.ts` (files are the source of truth; `write`, `read`, `list`, `edit`, `rename`, `remove`, `setMeta`, `reconcile`; `supersedes` marks the older decision superseded and adds a `supersedes` edge).
- `hooks/` — `session-start.ts` (routing guidance + project brief), `routing.ts` (suggest/annotate/deny, Agent prefix with brief, `symbolHints`, `coverageHint`), `capture.ts`, `pre-compact.ts`, `coexist.ts`, `log.ts`. `session/` — `brief.ts` (budgeted project brief), `guide.ts`, `current.ts`, `server-alive.ts`.
- `ui/` — `server.ts` (static `dist/ui` with mtime-versioned asset URLs, Host/Origin checks, JSON API routing), `api.ts` (stats, sessions, search, memories, legacy graph map/subgraph, actions), `graph-api.ts` (status, tree, file, file-impact, symbol, behavior, node search, graph expand/path, architecture, hotspots, routes, clusters, coverage, changes, runs). `ui/web/`: `app.tsx` (shell, tabs, theme, status bar), `router.ts` (hash routes `#/view?params`), `api.ts` (client + shared types), `components.tsx` (useAsync, Split, SubTabs, useSort, toast), `graph/` (`force.ts` d3-force layout + hierarchy, `GraphCanvas.tsx` canvas renderer, `treemap.ts` squarified treemap), `code/` (Prism highlighting, `CodeView`), `views/` (Overview, Explore, Galaxy, Architecture, History, Memory, Coverage, Sessions, System), `public/` (index.html, styles.css with the grey/blue tokens).
- `storage/` — `adapter.ts` interface, `types.ts`, `sqlite/adapter.ts` + `sqlite/schema.ts` (migrations v1–v4; the only SQL). `search/`, `index/`, `chunker/`, `sandbox/`, `permissions/`, `embeddings/`, `fetch/`, `stats/`, `capture/`, `install/` as before.

Hotspots by metrics score (2026-10-14): `src/storage/sqlite/adapter.ts`, `src/storage/adapter.ts`, `src/graph/query.ts`, `src/ui/api.ts`, `src/memory/store.ts`, `src/graph/treesitter.ts`, `src/storage/types.ts`, then `src/install/claude-config.ts`, `src/graph/reindex.ts`, `src/config.ts`, `src/ui/server.ts`, `src/hooks/routing.ts`. Entry points nothing imports: `src/server.ts`, `src/hook.ts`, `src/cli.ts`, `src/ui/web/main.tsx`, `src/stats/statusline.ts`, `src/install/{upgrade,uninstall,replace}.ts`, `scripts/*`; `src/ui/server.ts` and `src/embeddings/transformers.ts` are loaded via dynamic import so they also show as orphans. Graph on this repo: ~1280 nodes, ~5480 edges, 11 clusters (one 116-file core, `src/ui/web/` as its own cluster, small chunker/permissions/namepath clusters). One import cycle exists and is tolerated: `src/graph/languages/go.ts` → `languages/python.ts` → `treesitter.ts` → `go.ts` (the language modules import the shared loader from `treesitter.ts`, which dispatches back to them).
